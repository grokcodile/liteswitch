How it's built

One file

A single main.swift, no dependencies, compiled with swiftc. The whole app is 560 KB.

Nothing leaves

OCR, dictation and rewriting all run on your Mac. No account, no API key, no telemetry.

Built to shrink

Each tool covers a gap macOS misses by a hair. When a release closes one, the tool comes out.

Install

Download the notarized build from Releases, or build it yourself:

git clone https://github.com/grokcodile/liteswitch
cd liteswitch
bash install.sh

Needs macOS 26. Accessibility for the tools that synthesize keystrokes, Screen Recording for Capture Text, Apple Intelligence for Rewrite Text — each asked for only when first used.

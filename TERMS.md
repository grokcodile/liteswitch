## Privacy

Liteswitch runs entirely on your Mac, collects no data, and has no analytics or
telemetry. The only network request it makes is a version check against GitHub
Releases to offer updates. See the full [Privacy Policy](PRIVACY.md).

## Updates

Liteswitch checks GitHub for new releases. If you installed with Homebrew,
`brew upgrade --cask liteswitch` fetches them; otherwise new versions are on
[GitHub Releases](https://github.com/grokcodile/liteswitch/releases). You can
simply not install updates if you prefer.

## Payments

Liteswitch is completely free. Nothing is gated, and there are no accounts,
purchases, or subscriptions. The optional tip jar links to a third-party service
(Ko-fi) which has its own terms.

## What it depends on

Liteswitch is a shortcut onto features macOS already provides — Spotlight's
panels, Vision OCR, macOS dictation, Apple Intelligence, IOKit power assertions.
Those features are Apple's, and they can change or be removed in any macOS
release. A tool may stop working, or be removed from Liteswitch, when that
happens.
